# Roadmap

## Phase A — Rapid review
Modules 01–06. The goal is interview recall, not re-learning from zero.

## Phase B — Foundation-model core
Modules 07–11: Transformer → ViT → LLM/FM → Fine-Tuning/PEFT → VLM.

## Phase C — Decision and agentic AI
Modules 12–14: RL → world models → RAG/agents/coding agents.

## Phase D — AI systems
Modules 15–16: distributed/GPU systems → deployment/TensorRT/serving.

## How to study each chapter
1. Read the module `README.md` from beginning to end.
2. Re-derive the main equations without looking.
3. Use `interview_qa.md` for oral practice.
4. Use `references.md` only when a concept needs deeper primary-source reading.
5. Complete the chapter hands-on exercise or a project under `projects/`.

## Completion criterion
A topic is not considered done until you can:
- explain it without notes;
- write the key equations;
- answer tradeoff/comparison questions;
- connect it to a concrete implementation.
