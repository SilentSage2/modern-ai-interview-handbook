# Interview Answer Template

For "Explain X" questions:

1. **Definition** — one sentence.
2. **Why** — what problem it solves.
3. **Mechanism** — architecture/equation.
4. **Tradeoff** — compute, memory, data, robustness.
5. **Example** — one concrete use case.
6. **Comparison** — nearest alternative.
7. **Failure mode** — where it may break.

For project questions:

> Problem → data → baseline → method → training → evaluation → result → failure → what I would do next.
