# Model Taxonomy Cheat Sheet

- **Foundation model:** broad pretrained model intended for adaptation across downstream tasks.
- **LLM:** autoregressive or related foundation model focused on language/token sequences.
- **ViT:** Transformer applied to image-patch tokens.
- **VLM:** model jointly processing/aliging visual and language information.
- **Generative model:** models a data distribution or conditional distribution.
- **World model:** learned model of environment state/dynamics, often action-conditioned, usable for prediction/planning.
- **Agent:** system that repeatedly observes, decides, acts/uses tools, and incorporates resulting observations.
- **RAG:** retrieve external information and add it to model context before generation.
- **PEFT:** adapt a pretrained model while training a small subset/additional set of parameters.
